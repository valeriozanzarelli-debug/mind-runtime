🧬 ORGANISM

Installa Baby sul tuo PC Windows — locale, con webcam e microfono

versione — · Windows 10+
Scarica ORGANISM ORGANISM-Windows.exe

Come funziona

  1. Scarica ORGANISM-Windows.exe
  2. Doppio clic — Windows potrebbe chiedere “Esegui comunque”
  3. Si apre il browser su http://127.0.0.1:8765
  4. Consenti webcam e microfono
  5. Baby nasce, vede, sente, impara

Dove salva i dati

%USERPROFILE%\.organism\baby_state.json — memoria tra sessioni.

GPU (opzionale)

Per la retina neurale HD serve NVIDIA + driver aggiornati. Senza GPU funziona comunque in CPU.
