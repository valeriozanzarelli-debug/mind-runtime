🧬 ORGANISM

Cervello GPU sul tuo PC — finestra nativa, webcam, nessun browser

versione — · Windows 10+
Scarica ORGANISM ORGANISM-Windows.exe

Come funziona

  1. Scarica ORGANISM-Windows.exe
  2. Doppio clic — Windows potrebbe chiedere “Esegui comunque”
  3. Si apre una finestra nativa (OpenCV) — non il browser
  4. Consenti la webcam se richiesta
  5. Il cervello dendritico gira in locale; premi Q per uscire

Dove salva i dati

%USERPROFILE%\.organism\mindruntime\ — journal sessione e stato ultimo tick (solo disco locale).

GPU (opzionale)

Per la retina neurale HD serve NVIDIA + driver aggiornati. Senza GPU funziona comunque in CPU.
